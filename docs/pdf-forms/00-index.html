PDF Form Template Kit · V1

PDF 表单模板库

面向 PDF_FORM_GENERATE 工具的表单模板参考集。4 个模板覆盖主流表单形态， 共享同一套 design tokens 与字段协议 —— HTML 本身就是可解析的结构化 schema 源， 工具可直接读取 data-field 生成 AcroForm 字段。

01 行政流程

事项申请表

application · ADM-APPLY-001

分节流式布局 + 下划线填空 + 多选/单选组 + 三级审批栏。适合请假、采购、用印、用车等需要流转签署的行政事项。

字段 20形态 纵向流式页数 1
02 信息采集

员工信息登记表

registration · HR-REG-002

标签-值成对网格表格，信息密度最高；含证件照位、教育/工作/家庭子表与薪酬社保区。适合入职登记、客户建档、供应商备案。

字段 30+形态 网格表格页数 1
03 调研评估

满意度调查问卷

survey · CS-SUR-003

5 级量表矩阵 + NPS 0–10 横条 + 多选/单选 + 开放题。适合客户满意度调研、培训效果评估、内部敬业度调查。

字段 16形态 量表矩阵页数 1
04 财务单据

费用报销单

expense · FIN-EXP

可重复明细表（8 行）+ 金额合计（小写/大写）+ 收款信息 + 三级审批。适合差旅报销、日常费用报销、付款申请。

字段 20+形态 明细表格页数 1

字段协议 · Field Protocol

data-field字段唯一名，工具生成 AcroForm 时即作为字段名（snake_case）
data-typetext textarea number money date select radio checkbox rating nps signature table group
data-label中文标签，用于 AcroForm 的 tooltip / 无障碍标签
data-requiredtrue 时渲染必填星号，生成 PDF 时置为必填字段
data-repeatable仅 table 类型，标记明细行可动态扩展
data-checked选项的预填状态（单选 / 多选 / 量表 / NPS 通用）
<div class="field col-4"
     data-field="applicant_name"
     data-type="text"
     data-label="申请人姓名"
     data-required="true">
  <div class="field-label">申请人姓名<i class="req">*</i></div>
  <input class="ctrl ctrl--underline" type="text" placeholder="请输入姓名">
</div>
