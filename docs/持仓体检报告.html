组合风险与结构问题

① 赛道集中

宁德时代 + 比亚迪同属新能源车产业链，两只高度相关（需求 / 锂价 / 价格战同频），等权下占组合 1/3，等于半仓押注单一赛道。若新能源景气下行，两只会一起跌。

② 风格偏左侧

六只里四只 YTD 负收益，且主力 20 日全部净流出——组合整体偏「高位套牢 / 左侧承压」结构，缺「趋势向上」的进攻头寸，需靠再平衡提升组合弹性。

③ 逻辑待统一

组合既有防守（茅台 / 平安高股息）又有高弹性（宁德 / 恒瑞），但缺少统一框架：哪些是「看 3 年逻辑」、哪些是「看 1 个季度」，需要先分清再决定去留。
