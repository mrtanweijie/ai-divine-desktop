# 模型与深度思考等级 · 交互优化方案

> 现状：输入框左下单个 pill（`✦ 模型名 · 档位 ›`）→ 弹出二级菜单（模型分组列表 /
> 档位列表）。改一个维度需要 2 次点击 + 层级返回；档位语义弱；滑块隐喻与 4 个
> 离散档位冲突（可停在档位之间 = 非法态）；不感知模型能力差异。

## 1. 目标

1. 模型、思考等级两个维度**一步直达**，去掉层级返回；
2. 档位控件杜绝非法中间态，每档代价（速度/深度）可见；
3. 感知模型能力：不支持深度思考的模型不展示档位；
4. 按模型记忆档位：切回上次用的模型，自动恢复它上次的档位。

## 2. 方案：单入口不变，深度思考改为滑块直选

入口 pill（`✦ 模型名 · 档位 ›`）保持现状。点击弹出的面板由「两个菜单项 +
二级列表」改为**单面板**（对齐交互稿）：

```
┌──────────────────────────────────┐
│            高 ›                   │  ← 当前档位名（accent 高亮）
│       DeepSeek V4 Flash           │  ← 当前模型（点击仍进模型列表）
│                                   │
│  ●━━━━━━━━━●━━━━━━◉────●         │  ← 吸附式离散滑块（4 档）
│  关闭        低       高       最高 │
│  默认档位：平衡速度与深度          │  ← 描述随档位实时变化
└──────────────────────────────────┘
```

交互细节：

- **滑块即点即改**：点击刻度/拖动释放吸附到最近档位，立即生效，
  不再有「深度思考 › 低/高/最高」二级列表；
- 顶部档位名（accent）实时反映当前/预览档位；底部描述沿用
  `effortDescriptions` 随档位切换；
- **模型行交互不变**：仍从面板点击进入模型分组列表（保留现有 models 子层）；
- 键盘：滑块 `←/→` 换挡，`role="slider"` + aria 值域；
- 其余（按模型记忆档位 / 能力感知）见第 4 节，作为后续增量。

## 3. 快捷键（增量）

| 快捷键 | 行为 |
| --- | --- |
| `⌘/Ctrl + M` | 聚焦模型 pill / 打开模型列表 |
| `⌘/Ctrl + ↑ / ↓` | 思考档位在 4 档间循环（即时生效，pill 同步） |

档位循环时不弹层，pill 直接受焦并闪一下确认（高频用户零弹层换挡）。

## 4. 状态与持久化

| 项 | 规则 |
| --- | --- |
| 模型 | 维持现有 `modelId` 会话态 + 全局记忆 |
| 档位 | 现有 `sessionEffort` 逻辑之上，增加 `modelEffortMemory: Record<modelId, effort>`（localStorage） |
| 回退 | 全局设置 `think_default / reasoning_effort` 仍作为新会话默认；模型记忆优先于全局默认（用户显式选过的模型） |
| 发送 | 不变：`reasoning_effort` 仅在 think 开启时随请求发送 |

## 5. 改动清单

| 文件 | 改动 |
| --- | --- |
| `ModelEffortControl.tsx` | 面板重排为单面板：深度思考滑块（吸附 4 档）+ 模型行；删除 efforts 二级列表 |
| `ModelEffortControl.less` | 分段控件样式、pill 并排布局、禁用态 |
| `types.ts` | `ModelConfig.supported_efforts?: string[]` |
| `state/sessionEffort.ts` | 增加按模型记忆的读写（localStorage） |
| `pages/chat/index.tsx` | pill 拆分后的布局与 props 传递 |
| 后端 providers 配置（可选 P2） | 模型能力矩阵下发 `supported_efforts` |

不涉及后端协议改动（`reasoning_effort` 发送逻辑不变）。

## 6. 分期

- **P1**：单面板改版（深度思考滑块直选，模型行保留）；
- **P2**：按模型记忆档位 + 模型能力矩阵（`supported_efforts` 下发 + 禁用态）；
- **P3**（可选）：pill 上滚轮循环换挡、档位 tooltip 显示预估延迟/费用（若有数据）。
