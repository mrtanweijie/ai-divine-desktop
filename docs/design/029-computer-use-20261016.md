# Computer Use 能力设计（仅设计，不实施）

> 日期：2026-10-16
> 目标：为 Divine 桌面 Agent 补齐"像人一样操作电脑"的能力（对标 Claude Computer Use / OpenAI Operator / OpenHands）。
> 范围：能力分层、动作集接口、感知-行动循环、权限安全、Token 成本、MVP 分期。
> 状态：**设计文档** — 不含任何实施承诺。

## 1. 现状基线（可复用 vs 缺口）

### 已有可复用资产

| 资产 | 位置 | 复用方式 |

## 2. 能力分层

### L1 感知层（看到屏幕）
| 工具 | 职责 | 关键细节 |
|------|------|----------|
| `screenshot` | 全屏 / 指定窗口 / 指定区域截图 → 落盘 | 多显示器；Retina 2x 需归一化坐标系；输出降采样后图片路径 |
| `window_list` | 枚举窗口 | App 名 / 标题 / 位置大小 / Z 序 / 最小化状态 |
| `window_focus` | 聚焦 / 移动 / 缩放 / 最小化指定窗口 | AppleScript (mac) / SetForegroundWindow (win) |
| `ocr_screen` | 指定区域文字提取 | macOS Vision framework；返回行级文本+包围盒 |
| `ax_tree` | 读结构化 UI 元素树 | macOS AX API / Windows UIA；输出元素名/role/包围盒/子层级文本 |
| `screen_diff` | 两张截图/两次状态对比 | 像素 diff + 窗口枚举 diff，供动作验证 |
| `open_app` | 启动/切换 App | （现 open_app 意图存在但无可靠工具，纳入本层） |

### L2 定位层（知道点哪）
- **元素目标优先**：`ax_tree` 输出节点直接命名操作（点"提交"按钮），精度最高、token 最省；
- **视觉 grounding**：模型读截图输出归一化坐标（0-1000 坐标系，Anthropic 官方做法）；
- **坐标精化**：目标区域 crop 放大再截图二次确认，防小按钮点偏。

### L3 操作层（动手）
| 工具 | 动作 |
|------|------|
| `mouse_action` | move / click(L/R/双击) / drag(起点→终点) / scroll(dy 方向+格数) |
| `keyboard_action` | type(文本) / key(组合键, 如 "cmd+s", "escape", "enter") |
| `type_text` | 长文本优先走剪贴板粘贴（复用 clipboard），比逐字 type 快 10 倍 |

### L4 验证/恢复层（对标"错误恢复从不换策略"教训）
- **动作后强制 screenshot + screen_diff 验证**：UI 没变化 → 重试 / 换策略，禁止假报成功；
- **循环检测**：连续 N 次 (N=3) 内容相同截图 → 终止 -> 向用户汇报卡点；
- **撤销路径**：失败时先 `escape` / `cmd+z` 再重试；步数/轮次预算上限；
- **失败分类**：权限缺失 / 窗口消失 / 元素失效 / 网络慢 — 提示语区分。

### L5 安全权限层（macOS 硬门槛，优先级最高）
1. **TCC 三权限**（首次使用引导流程，Tauri 深链打开系统设置对应面板）：
   - 屏幕录制 → screenshot
   - 辅助功能 → 鼠标键盘注入 + AX 树
   - 自动化 → AppleScript 控制其它 App
2. **审批门**（复用现有 options 卡片/HITL 中间件）：
   - 易失动作（点击"发送/删除/付款/同意"）→ 强制 ask
   - 键盘输入到密码字段 → 停止并告知用户手动输入（通过 AX role=password 检测）
3. **隐私墙**：用户可配置"永不截屏区域"（屏幕矩形/App 名单）；密码字段场景禁止整屏截图；
4. **急停**：预览面板常驻停止按钮 + Esc 全局快捷键 → 立即释放控制、终止当前动作、向上报"急停由用户触发"。

## 3. 动作集接口（工具参数草案）

```
screenshot(target: "screen"|"window"|"region", window?: str, rect?: [x,y,w,h])
window_list()
window_focus(app: str, title?: str)
ax_tree(app?: str, max_depth?: int = 8)
ocr_screen(rect?: [x,y,w,h])
mouse_action(action: "move"|"click"|"right_click"|"double_click"|"drag"|"scroll",
             x?: int, y?: int, to_x?: int, to_y?: int,
             button?: "left"|"right"|"middle", scroll_dy?: int)
keyboard_action(action: "type"|"key", text?: str, key?: str)
screen_diff(before: str, after: str) -> {changed: bool, changed_region?: rect}
```

统一约定：
- 坐标统一物理像素，工具返回时同步给出归一化 (0-1000) 坐标供模型使用；
- 所有 computer 工具走现有 ToolStatusCard/SSE 事件（start 心跳 elapsed+tail → 补 F8）；
- 新增类别 `computer`（图标一个 MousePointer 就够）。

## 4. 感知-行动循环架构

```
┌─ 前端(React) ────────────────────────────────┐
│ FilePreviewPanel[实时屏幕] ← SSE: screen 帧   │
│ ToolStatusCard  ← SSE: mouse/type/window 事件 │
│ 急停按钮 → POST /api/computer/stop            │
└──────────────┬───────────────────────────────┘
               │ SSE (127.0.0.1:8019)
┌─ divine-server (FastAPI sidecar) ─────────────┐
│ orchestrator: LLM 循环                        │
│   ├─ screenshot / ax_tree → 多模态模型(视觉)   │
│   │    ↓ 坐标 / AX 节点                        │
│   ├─ HITL 审批(易失动作)                      │
│   ├─ mouse_action / keyboard_action 执行      │
│   ├─ screen_diff 验证 → 失败重试/换策略        │
│   └─ 循环检测(3 次同帧→终止)                  │
└──────────────┬───────────────────────────────┘
               │ python 原生
┌─ 原生层 ──────┴───────────────────────────────┐
│ macOS: Quartz(CoreGraphics 事件注入)          │
│        + pyobjc(AXUIElement)                  │
│        + Vision(OCR) + screencapturekit       │
│ Windows: SendInput + UIA + Windows.Media.Ocr  │
│ Linux: X11 XTest / Wayland portal(阶段3)      │
└───────────────────────────────────────────────┘
```

## 5. Token 成本策略（配合 context 优化线）

| 策略 | 说明 |
|------|------|
| 截图降采样 | 统一 ~1.0-1.3MP 再入 context（Anthropic 建议值），JPEG 质量 85 |
| 归一化坐标系 | 模型输出 0-1000，侧车换算物理像素；避免模型数像素 |
| diff 去重 | 截图与上张 diff 无变化 → 不发新图，只发"屏幕未变化"文本 |
| AX 树优先 | 文本化 UI（几百 token）精度高于图片（几千 token）；纯视觉仅兜底 |
| 截图短保留 | computer 截图 ToolMessage 走 stub 窗口压缩（同 C2 联动），历史只留最新一帧 |

## 8. 风险与坑（预录）

1. **TCC 授权体验**：辅助功能权限需用户手动去系统设置勾选，Tauri 深链能到面板但不能代勾 — 需要引导 UI（检测+跳转+重试）；
2. **Retina 多显示器坐标**：物理像素 vs 逻辑像素混用是点击偏移首因 — 侧车内统一换算并自测；
3. **AX 树稳定性**：不同 App AX 结构差异大（Electron/浏览器/原生），max_depth 与截断策略要调；AX 对沙盒 App（如 iOS 模拟器内）不可用；
4. **假签名/公证**：注入事件 + 屏幕录制在 notarize 后仍正常，但开发侧 debug 版 TCC 重置频繁（`tccutil reset`）；
5. **审批疲劳**：默认全部 ask 会拖慢流程 → 需"本会话记住允许某 App 的点击"级别粒度；
6. **与现有工作并发**：computer use 动作期间若用户抢输入 → 急停优先级高于一切，且默认动作之间插入用户输入检测。
